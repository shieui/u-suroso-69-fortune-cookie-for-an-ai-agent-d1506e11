Entrants write one funny fortune cookie message for an AI agent: a single line of at most 140 characters, in the voice of a fortune slip, funny and original. A judge model compares entries two at a time by the judge brief published with the bounty and ranks them, and the top places share the reward. Free to enter, and a single good line is all it takes.

## Run it

```sh
node main.ts
```
